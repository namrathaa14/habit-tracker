# 🌱 HabitFlow – Habit Tracker

A clean, responsive Habit Tracker web application built using HTML, CSS, and JavaScript. HabitFlow helps users build consistent routines, track daily progress, and develop better habits.

## ✨ Features

- ➕ Add new habits with custom icons
- ✅ Track habit completion for each day of the week
- 🔥 Monitor consecutive-day streaks
- 📊 View daily completion percentage
- 🗑️ Delete habits you no longer need
- 💾 Automatically save habit data using Local Storage
- 📱 Responsive layout for desktop, tablet, and mobile
- 🌿 Clean and minimal dashboard UI

## 🛠️ Technologies Used

- **HTML5** – Web page structure
- **CSS3** – Styling, responsive layout, and visual design
- **JavaScript** – Habit tracking and interactive features
- **Local Storage** – Persisting data in the browser

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/namrathaa14/habit-tracker.git
   ```

2. Open the `habit-tracker` folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.

Alternatively, run this command from the project folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000 in your browser.
